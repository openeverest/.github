# Security Policy

The OpenEverest security policy covers every repository in this organization.

Please read the full policy, including supported versions and the response process, in [openeverest/openeverest/SECURITY.md](https://github.com/openeverest/openeverest/blob/main/SECURITY.md).

**Do not report vulnerabilities publicly.** Report them privately through a [GitHub Security Advisory](https://github.com/openeverest/openeverest/security/advisories/new) or in the affected repository's **Security** tab.
